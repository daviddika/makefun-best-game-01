**Lumen Drift** is an original arcade arena shooter: you are a lantern moth drifting through a void nebula, harvesting starlight, dodging voidborn shards, and fighting through 10 escalating waves to shatter the Void Queen. Five enemy types (chasers, orbiting spinners, splitters that break into sparks, fast shards, and the boss herself), a combo multiplier, starlight pickups, hull-repair hearts, shield pickups and screen-clearing nova bombs, synthesized WebAudio sound effects and a generative music loop — all in plain static files with no libraries and no network requests. Keyboard + mouse, offline, in any desktop browser.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — click or press Enter to begin. Move with WASD or arrow keys, aim with the mouse, hold click or Space to fire, E or right-click for a nova bomb, P to pause, M to mute, R to restart.
